# Политика конфиденциальности — keen-pbr Quick Add

Обновлено: 12 октября 2026 года.

keen-pbr Quick Add — независимое расширение, которое поддерживает пользователь
GitHub [bakkewhite](https://github.com/bakkewhite). Его назначение — проверять,
добавлять и удалять домены в списках keen-pbr пользователя.

## Какие данные используются

При открытии расширения или нажатии «Из вкладки» читается URL/название текущей
вкладки. Можно ввести домен или URL вручную. Адрес нормализуется на компьютере:
убираются схема, путь, параметры и префикс `www.`, реальные поддомены сохраняются.
История посещений не сохраняется. Расширение не читает содержимое страниц,
cookies, поля форм или пароли на сайтах.

Для проверки читается конфигурация выбранного keen-pbr. Если есть списки по
URL/файлу, нормализованный домен также отправляется в диагностику маршрутизации
на этом сервере; она может выполнить DNS-запрос. Подписки браузером не скачиваются.
Добавление/удаление изменяет конфигурацию только после нажатия соответствующей
кнопки. Ответы API и списки доменов хранятся в памяти текущей операции, без
журналирования и сохранения расширением.

## Хранение и удаление

В профиле Chrome без синхронизации сохраняются адреса подключений, отдельный
список по умолчанию для каждого адреса и язык интерфейса. Временные отметки
незавершённой настройки в localStorage содержат только адрес сервера, без пароля;
они удаляются при сохранении или отмене настройки.

После явного входа учётные данные Basic для выбранного адреса по умолчанию
хранятся в `chrome.storage.session` до перезапуска браузера. Если включить
«Запомнить на этом компьютере», они остаются в `chrome.storage.local` до
«Забыть пароль», удаления подключения или данных расширения. Это не шифрование
пароля: программы с доступом к профилю Chrome могут его прочитать. Учётные
данные не передаются между разными адресами.

Отмена новой незавершённой настройки удаляет её временные учётные данные;
отмена редактирования сохранённого подключения его пароль не удаляет.
Удаление подключения удаляет локальный профиль и его пароль, но не меняет
роутер и не выбирает другое подключение автоматически. Ранее выданные разрешения
на адреса сохраняются; их можно отозвать в настройках расширения Chrome.
Удаление расширения или его данных в Chrome удаляет сохранённые настройки.

## Передача данных и разрешения

Запросы идут напрямую на адрес keen-pbr, который указал пользователь.
Серверов-посредников разработчика, телеметрии, аналитики, рекламы и удалённого
исполняемого кода нет. Данные о работе расширения разработчику не передаются.

HTTPS шифрует соединение. HTTP для пользовательских серверов поддерживается,
но не шифрует запросы и пароль; перед вводом пароля интерфейс предупреждает
об этом. Используйте HTTPS или доверенную локальную сеть.

`activeTab` нужен для адреса текущей вкладки по действию пользователя, не для
фонового отслеживания истории. `storage` нужен для описанных настроек и
учётных данных. Необязательное разрешение HTTP/HTTPS запрашивается для выбранного
адреса API. В манифесте допускаются произвольные адреса, поскольку локальные
адреса, порты и имена KeenDNS у пользователей различаются; доступ ко всем
сайтам одновременно не запрашивается.

Роутер или настроенный пользователем прокси может журналировать запросы и
обращаться к своему DNS-провайдеру. Это контролирует оператор сервера, не
расширение. Кнопка открытия Web UI — обычный переход браузера на выбранный адрес.

## Ограничение использования и связь

Данные используются только для управления списками доменов в соответствии
с Chrome Web Store User Data Policy, включая требования Limited Use.
Расширение не продаёт данные, не использует их для рекламы или оценки
кредитоспособности и не предоставляет разработчику доступ к данным роутеров.

Вопросы можно задать через
[GitHub Issues](https://github.com/bakkewhite/keen-pbr-quick-add/issues).
Не публикуйте пароли, частные адреса роутеров или полные конфигурации.
На добровольно отправленные в GitHub сообщения распространяется политика
конфиденциальности GitHub. Обращение в поддержку не требуется для работы
расширения.
